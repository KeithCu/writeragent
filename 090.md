## Already shipped in the 0.8.85 line

If users last installed **`0.8.84`**, they already had Harper status-bar fixes and optional Python **file / OS / network** sandbox flags. The **0.8.85** line adds:

- **Reasoning effort** — Sidebar control next to the model selector; per-endpoint/model preference is remembered (`reasoning_effort` in settings / LRU). Providers map effort with step-down and retry on unsupported values.
- **CodeMirror 6 script editor (optional)** — **Settings → Python →** `scripting.python_editor` chooses **`monaco`** (default) or **`codemirror`**. CM6 supports Jedi parity, error markers, LaTeX in the script editor, unsaved-change prompts on script switch, and shared behavior with the Monaco shell.
- **Writer indexes** — Table-of-contents listing no longer returns empty when body text appears above the TOC anchor.
- **Vision in chat** — `get_image` results are sent to the model as **image parts**, not base64 stuffed into tool text (all apps that expose `get_image`).
- **Honest truncation** — Length-capped reads and delegate replies return **`incomplete`** (with message), not silent **`ok`**, so the agent knows content was cut off.
- **Dependencies** — Pillow 13, urllib3 2.8, websockets 17.4, compute image packages, and related dev bumps (#2517).

## New in 0.9.0

### Chat sidebar, slash commands, and modes

- **Slash commands (shipped)** — Typing **`/`** in the Ask box opens a completion popup (**14** commands on the shipped list: `help`, `clear`, `stop`, `summarize`, `proofread`, `shorten`, `expand`, `tone`, `translate`, `explain`, `remember`, `compact`, `undo`, `formula`). **`/help`**, **`/clear`**, **`/stop`**, and **`/undo`** run immediately from the popup; others insert **`/name `** for arguments. **Send** intercepts a full slash line and runs the preset instead of a raw chat turn. Popup rows and **`/help`** respect the active app (`SlashCommand.apps`); typed commands outside an app print a short notice (e.g. **`/formula`** only in Calc).
- **Rewrite presets on Draw/Impress** — Slash rewrite presets (**`/proofread`**, **`/shorten`**, **`/expand`**, **`/tone`**, **`/translate`**, etc.) rewrite the **selected text shape** in place; without a text shape, the sidebar shows **“Select a text shape.”** (tables are not rewritten). **Edit Selection** and the same presets share that path on slides.
- **Calc slash fallbacks** — Calc rewrite presets can target the **used range** when the sidebar preset path allows whole-document edit and the selection does not overlap the used range.
- **Deep Research in all apps** — **Deep Research** sidebar mode is available in Writer, Calc, Draw, and Impress (not a Draw-only modal). App-specific slash filtering, Calc/Draw **agent manual** text, and keyboard dead-key fixes ride along (#3202).
- **Stop and cancellation** — One **Stop** convention across chat, streaming LLM, MCP/ACP turns, TTS, and web approval; Stop aborts network waits but still lands completed document mutations and finishes speech-to-text into the query box (does not discard audio or auto-send). MCP tunnel stops when LibreOffice exits (#3119).
- **Child-process supervisor** — Long-lived **venv Python worker**, **Kokoro TTS**, and **STT** register with a shared warm-child **Supervisor** so quit and Stop tear down subprocess trees predictably (#3121–3125).
- **Prompt caching** — Document snapshot ordering and stable request prefixes improve provider-side prompt cache hits (#3080, #3085).

### Writer (core and specialized)

- **Document properties (specialized `fields`)** — **`document_properties_get`** / **`document_properties_set`** read and write built-in and user-defined document properties (moved under the **fields** specialized domain, not the main chat list).
- **Comments** — **`comment_edit`** plus paged **`comment_list`** for threaded comment workflows.
- **Text frames (specialized `textframes`)** — **`frame_list`**, **`frame_get_info`**, **`frame_set_properties`**, **`frame_insert`**, and related frame tools for floating text boxes.
- **Embedded objects** — **`embedded_insert`** inserts a **real OLE** embedded object (not a placeholder stub).
- **Grammar / Harper** — **Harper remains English-only** for locale lint; status flows through a shared **GrammarStatus** sink so the status bar and sidebar stay consistent. HarperRuntime encapsulation and grammar settings modules reduce duplicate queue paths.
- **Reviewable edits** — **`/undo`** (slash) and compound undo improvements: clearer “last agent edit” rollback when the undo stack allows it.
- **Tool naming** — Many Writer specialized tools follow **`domain_verb`** naming (consistent with Calc/Draw); schemas and docs were refreshed in PR **#3214**.

### Calc (core and specialized)

- **Workbook lifecycle** — **CellContext** and **WorkbookState** give `=PY()` / formula tools a single workbook lookup, debounced recalc, and safer unload when sheets change (#3142, #3198).
- **Sheet operations (specialized `sheets`)** — **`sheet_copy`**, **`sheet_move`**, **`sheet_hide`**; **`sheet_list`** returns **`{name, protected, visible}`** objects instead of bare names.
- **Range structure (core)** — **`insert_structure`** inserts rows or columns; **`merge_cells(unmerge=true)`** splits merged ranges without forcing centered merge layout.
- **Addresses** — Sheet-qualified addresses on structure tools and **`insert_cell_html`**; case-insensitive sheet names in address keys.
- **Styles** — **`style_list`** with **`family='CellStyles'`** on Calc for conditional-formatting workflows.
- **Vision** — Core **`get_image`** on Calc for embedded graphics / selection; **`page=`** remains invalid on Calc (Writer/Draw/Impress only).
- **Charts (specialized `charts`)** — **`manage_charts`** replaced by four tools: **`chart_list`**, **`chart_get_info`**, **`chart_upsert`**, **`chart_delete`** (Calc, Writer, Draw/Impress via delegation).
- **Reads** — **`read_cell_range`** peek uses **compact row format** by default; typed **2-D `values`** arrays for bulk writes.
- **Multi-cell edit selection** — Grouped Calc cell edits from Edit Selection collapse into **one undo** step.

### Draw and Impress (core and specialized)

- **Page comments (specialized `page_comments`)** — **`page_comment_list`**, **`page_comment_add`**, **`page_comment_delete`** for slide/page annotations on Draw and Impress.
- **Search** — **`search_slides`** across shape text and speaker notes.
- **OCR** — Draw/Impress **OCR** path for slide content (compute/vision stack); missing OCR backend in the external service returns a clear **501**, not an opaque failure.
- **Shapes** — **`shape_align`**, **`shape_distribute`**, **`shape_diagram`**, naming, layout on Writer/Calc as well as Draw; **grouped shapes** addressable by **dotted path**; slide **tables** and **groups** tooling expanded (#3203).
- **Edit Selection on slides** — Same rewrite preset behavior as slash commands for text shapes (#3209).
- **PPT-Master** — Client/host path hardening for template-driven deck work (main-thread wrappers, typed table context); not a separate product—see specialized **`ppt_master`** domain docs.
- **Still specialized-only** — Slide animations, layer management, slideshow controls, AV insert, 3D manipulation, and **`transform_document_structure`** remain **unshipped** (dummy/unregistered).

### Python, LibrePy, and compute service

- **Compute service** — HTTP **keep-alive**, admission/timeouts, **`child_runtime`** in the Docker bundle, route table with stable **error codes**; **numpy domain helpers** can run in the compute service when configured (#3205, #3200, #3156). **Both** JSON “peel” and **multipart** execute ingress are supported; multipart is the preferred long-term wire—this is **not** the same as unshipped **Calc dynamic-array engine spill** (see `docs/scripting/ms-py-compatibility.md`).
- **Sandbox** — **Allow file access** (and related gates) enforce reads/writes when enabled in Settings; external compute service **does not** honor WriterAgent sandbox flags yet (documented limitation).
- **`=PY()`** — Whole-number Calc arguments may arrive as Python **ints**; **`repr`** allowed in sandbox where previously blocked.

### Voice (STT / TTS)

- **TTS** — Voices and response format follow **model** capabilities, not a stale per-endpoint memo; unified cancellation with chat Stop.
- **STT** — Supervisor-backed lifecycle; Stop ends the take and transcribes into Ask without auto-submitting to the model.

### MCP server and ACP agent backends

- **MCP** — Clearer **MCP-off** status in UI; **`document_url`** wording aligned with open-document keys; **`prompts/list`** and **`prompts/get`** for prompt discovery; **`search_nearby_files`** accepts **`doc_url_filter`**; tunnel **session token** and **Tailscale** provider subclass; CORS and mutation-gate behavior documented in **`docs/mcp-protocol.md`** (#3210, #3056, #3214).
- **ACP** — **Antigravity** via **`agy acp`** (sign-in with **`agy`** / **`agy acp --login`**, not a WriterAgent API key). Fixes for **agy** MCP null-in-enum, model pick, and error surfacing (#3206, #3212).
- **Existing backends unchanged in principle** — Hermes, Claude Code, Mistral Vibe, Grok Build, OpenCode still route through ACP; optional **OpenAI Responses API** path exists for supported GPT models (opt-in plumbing—not a separate user-facing mode).

### Cross-document intelligence (unchanged scope, clearer docs)

- **Peer messaging** — **`send_peer_work`** / **`send_peer_result`** remain **`document_research` specialized only** (not main chat, not MCP). Requires peer documents **already open** in the same LibreOffice process; no spawn. Post-**#814** outer agent must re-delegate after peer work envelopes. (Land date before the 0.8.85 feature tranche; still the supported cross-app story in 0.9.0.)
- **Embeddings / folder search** — Corpus metadata, cancel-scope hygiene, and doc-identity fixes for notebook/vision batches; product capabilities as in **`docs/embeddings.md`**.

### Localization

- **34 translated locales + English source** (README/docs aligned in #3214)—not 35.

## Notable fixes and reliability (user-visible)

- **Calc / Writer / MCP** — Self-referential save guards, disposal propagation to undo, MCP tunnel port and timeout fixes, stemmer edge cases (#3030).
- **Indexes / TOC** — TOC paragraph walk stops only after the anchor end (#2260).
- **Images** — Size image edits from the **base-size grid**, not raw file pixels (#2810).
- **Draw** — Page index omitted for shapes inside groups when appropriate (#2241).
- **Scripts manager** — Read-only fallback no longer drops later edits (#2248).
- **Release build** — PPTX import test fix on endpoint commit `fbb283879`.

## Still not shipped (do not promise in 0.9.0)

- **Calc engine dynamic spill** / MS-PY parity spill—platform-scale work, not this extension release.
- **`transform_document_structure`** (Draw DSL)—module intentionally dummy/unregistered.
- **ComfyUI / Diffusers** image backend—plan only (`docs/images/diffusers-comfyui-dev-plan.md`).
- **MCP exposure of peer send tools**, **blocking A2 `ask_peer_*`**, spawn-peer, PDF/AcroForm product.
- **Multi-document `@` mentions**, extra-directory reads beyond shipped folder search—see **`docs/chat/multi-document-dev-plan.md`**.
- **Responses API** as default chat transport—opt-in/low-level; most users stay on chat completions.
- **Compute service honoring WriterAgent Python sandbox toggles**—still LibrePy/WriterAgent in-process only.

## Optional specialized domains (reminder)

Writer, Calc, and Draw/Impress each expose **core** chat tools plus **specialized** domains (pages, shapes, charts, fields, comments, python, web_research, document_research, etc.). The main agent must **`delegate_to_specialized_{writer|calc|draw}_toolset`** to reach specialized tiers; MCP **`tools/list`** uses its own tier rules (`tier="mcp"` vs `"core"`). Counts and domain lists: **`docs/writer/specialized-toolsets.md`**, **`docs/calc/specialized-toolsets.md`**, **`docs/draw/impress-specialized-toolsets.md`**, refreshed in **#3214**.
