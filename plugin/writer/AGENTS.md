## Sharp edges

- Writer `charts` / `shapes` share tool **names** with Calc/Draw — the Writer class must declare the **union** of those UNO services or execution rejects the document.
- Extend / Edit selection prompts must use `get_string_without_tracked_deletions()` in `text_helpers`, not a raw text dump that includes tracked deletions. If that selection already contains a tracked Insert or Delete, both commands stop and show a message. `WriterStreamedRewriteSession` and `WriterStreamedAppendSession` raise `TrackedChangesInSelection` before `setString` and before changing `RecordChanges`. A selection with no Insert/Delete redlines keeps the current rewrite, including an empty model result (do not write `original_text` back when the model returns nothing). `wait_for_review` completes on a reliable empty intersection of redline comments with **registered** change tokens. An orphan `wa-review:<session>:<n>` left when tagging or the missing-bookmark clear failed must not keep the wait blocked, and an unreliable redline scan still fail-closes. Do not register that orphan, and do not special-case an empty bookmark in `_outcome`.
- CJK ruby is portion marks (`RubyText` on the start mark), not a text field. `get_document_content` emits `<ruby>…<rt>…</rt></ruby>` on read. `apply_document_content` strips `<rt>` then sets `RubyText` on the base (StarWriter import concatenates). Search/`getString()` are base-only. See [docs/writer/ruby.md](../../docs/writer/ruby.md).
- Do not import `document_helpers` from LibrePy paths (WriterAgent chat context / `DocumentService`). Light helpers stay in `text_helpers` / `doc_type` / `udprops` and are **not** re-exported from `document_helpers`.
- Search-replace of text inside an outline hyperlink (`#…|outline`) rewrites that `HyperLinkURL` when the matched text occurs once outside the trailing `|outline` (`hyperlink_fixup`). A hit that overlaps that suffix is skipped, so `line` in `#1.The line.|outline` still becomes `#1.The row.|outline`. A repeated title is left unchanged until `hyperlink_url` sets the target. `content` may equal `old_content` in that override, so a title that is already correct can still get a new URL. The write covers the whole link, not only the replaced characters. A match that overlaps two hyperlinks does not receive one URL across both. Bookmark targets (`#__RefHeading___Toc…`) are left alone. `hyperlink_url` applies only when the match overlaps exactly one outline link: it is rejected with `all_matches` and otherwise. Portion walks must use `_enum_has_more` (`hasMoreElements() is True`). `if not enum.hasMoreElements()` never stops on pytest `MagicMock` (the return is another mock). `pull_request` CI checks out the merge with the base branch, so those unit tests hang there while `workflow_dispatch` (branch SHA only) stays green. Assigning `HyperLinkURL` on a *subrange* of an already-linked TOC line (the title only) splits that portion and reapplies Internet-link defaults (navy + single underline) on the title and leftover punctuation/tab. `restore_outline_hyperlinks` skips that title-only paint when the replacement already has the new URL (the whole-span write did it). When a paint is still needed, it snapshots `CharColor` / `CharUnderline` after the text replace and writes them on the same cursor.
- `indexes_refresh_toc_entry` rewrites one TOC substring in place and does not call `update()`. Page numbers, other entries, and direct formatting stay (the outline URL write does not re-paint the title as a subrange when that URL is already current). `indexes_insert_toc_entry` and `indexes_delete_toc_entry` add or remove one row the same way: no `update()`, neighbors stay, protection is restored, and a failure rolls back the undo context. Insert clones the sibling `Contents N` style, character props, and tab stops, and writes the page as plain text after a tab (generated rows are digits in the entry, not a page field). `hyperlink_url` on insert may be `#…|outline` or `#Name|table` (LibreOffice's text-table target; `table:Name` is only a navigation locator). A `|table` URL is stored as given and is not rewritten when that row's title changes. `indexes_update_all` is still the full rebuild, and that rebuild drops customized TOC formatting. The agent compares the outline and decides; indexes does not sync the TOC. `indexes_list_toc_entries` lists those rows (visible text, Contents N level, HyperLinkURL) from the index paragraphs. It does not call `update()` and does not send the TOC through `get_document_content`'s XHTML export.
